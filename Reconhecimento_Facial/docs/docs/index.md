# Reconhecimento_Facial

Controle de acesso por reconhecimento facial com OpenCV e DeepFace.

## Comandos

* `make cadastrar` - Cadastra as pessoas de `data/autorizados`.
* `make reconhecer` - Verifica as fotos de `data/teste` e grava o resultado em `reports/resultados`.
* `make webcam` - Controle de acesso ao vivo pela webcam.
* `make avaliar PASTA=...` - Mede falsos aceites e falsas rejeições em uma base rotulada.

Detalhes de funcionamento, segurança e calibração no README do projeto.
