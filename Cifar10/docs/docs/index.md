# Cifar10

Classificador de imagens CIFAR-10 com rede neural convolucional.

## Comandos

* `make data` - Baixa a CIFAR-10 e salva em `data/raw/cifar10.npz`.
* `make train` - Treina a CNN e salva em `models/cnn_cifar10.keras`.
* `make evaluate` - Avalia o modelo salvo no conjunto de teste.
* `make plots` - Gera as figuras em `reports/figures`.
